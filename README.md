# LLM Speedrun

The point of this repo is to start from an implementation of LLM (GPT-2) training on a single GPU and gradually apply optimizations that will make the training as efficient as possible. Once I am satisfied with the single GPU performance I plan to run it on multiple GPUs. To increase iteration speed, I will do initial testing on the TinyShakespear dataset and then once I am satisfied, I will eventually try to run it on the fineweb dataset to see how my implementation compares to the nanogpt speedrun record.
